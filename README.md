# Android Calculator - With History

## 📌 About the Project
This is a mobile application developed in **Android Studio** that performs basic mathematical operations. The main focus of this project was to implement a **calculation history** feature, allowing users to track and review their previous operations during a session.

## 🚀 Features
- Basic operations: Addition, subtraction, multiplication, and division.
- A dedicated list that stores and displays previous calculations.
- Clean and intuitive UI designed for a smooth mobile experience.
- Option to clear the current display or the entire history.

## 🛠️ Technologies Used 
- **Android Studio**
- **Java**
- **XML**
